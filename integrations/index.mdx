Use fallow where you already work: in your agent, your editor, and your pipeline.

- **Agents**: structured output and MCP tools
- **Editors**: real-time feedback while you code
- **CI**: review comments and merge gates

## Recommended starting point

- **Developer**: start with the CLI, then add VS Code.
- **Agent user**: start with CLI JSON output, then add MCP.
- **Team rollout**: start with CI, then add runtime intelligence later.
