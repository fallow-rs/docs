Install the fallow skills, so that your coding agent runs the right fallow command for a task and reads the output correctly.

A **skill** is a folder with a `SKILL.md` file and reference files. The agent reads the description of each skill, and loads the skill when a task matches. The fallow skills follow the open [Agent Skills](https://agentskills.io) format, so each agent that reads this format can use them.

## Before you start

- Add fallow to the project: `npm install --save-dev fallow`. The skills run the CLI.
- Read [Fallow for coding agents](/integrations/agents). It recommends `npx fallow agent install`, which installs the skills together with the other parts.

## Install the skills

Use one of these ways. Each way installs the `fallow` skill.

| Way | Command | Skills |
|:--|:--|:--|
| Into the project, for Claude Code, Codex and Cursor | `npx fallow agent install --without mcp --without hooks` | `fallow`, `fallow-setup` |
| Claude Code plugin | `/plugin marketplace add fallow-rs/fallow-skills`, then `/plugin install fallow@fallow-skills` | All skills in the table below |
| Codex plugin | `codex plugin marketplace add fallow-rs/fallow-skills`, then `codex plugin add fallow@fallow-skills` | All skills in the table below |
| Another agent | `npx skills add fallow-rs/fallow-skills`, or `npx skills add fallow-rs/fallow-skills --agent <name>` | All skills in the table below |
| Gemini CLI | `gemini skills install https://github.com/fallow-rs/fallow-skills.git` | All skills in the table below |

`fallow agent install` copies the skills from the fallow binary into the project. Claude Code reads them from `.claude/skills/`, and Codex and Cursor read them from `.agents/skills/`. Commit these folders, so that each team member gets the same skills. Remove `--without mcp --without hooks` to also install the MCP server and the [commit gate](/integrations/claude-hooks), a hook that runs `fallow audit` before the agent commits.

The [fallow-skills](https://github.com/fallow-rs/fallow-skills) repository holds the plugin, with more skills than the fallow package.

## Keep the skills current

The skills describe the options of one fallow version.

- A project copy comes from the fallow binary that wrote it. After an update of fallow, run `npx fallow agent install` again. `npx fallow agent status` shows a copy from an older fallow as `stale`.
- A plugin follows the releases of the fallow-skills repository. Update the plugin with the plugin manager of your agent.

`fallow agent install` replaces only the files that it wrote. To replace a skill that fallow did not write, add `--force`.

## The skills

| Skill | Source | What it does |
|:--|:--|:--|
| `fallow` | fallow package, plugin | Runs fallow for code health questions: changed-code risk, unused code and dependencies, duplication, complexity, architecture and runtime coverage. |
| `fallow-setup` | fallow package, plugin | Sets up code-quality tooling for a JavaScript or TypeScript project: it detects the tools, installs fallow, sets up the agents and adds a CI gate. |
| `fallow-review` | plugin | Reviews a branch or a pull request with the review brief of fallow, ranked by risk. |
| `fallow-mutation` | plugin | Improves the tests of a change with `fallow mutation`. It runs the tests of the project many times. |
| `fallow-cloud-setup` | plugin | Connects an app to Fallow Cloud for runtime coverage. |
| `cargo-fallow` | plugin | Runs `cargo fallow` on a Rust workspace. |
| `fallow-codex-onboarding` | plugin | Sets up the Fallow app in Codex after the install. |

The `fallow` skill has reference files for the CLI, the MCP tools, the issue types and common mistakes. The agent reads them only when the task needs them.

## Check the result

Ask the agent for a task that the skill covers, for example "find the unused exports in this project". The agent then runs a `fallow` command with `--format json`.

For a project copy, run `npx fallow agent status`:

```text
  .claude/skills/fallow                     absent      skill (claude)
  .claude/skills/fallow-setup               absent      skill (claude)
```

`absent` means that the install did not write the skill. After the install, the state is `installed`.

## If it fails

- **The agent does not use the skill.** Start a new session after the install, and name fallow in the request.
- **The agent uses options that do not exist.** The skill is from an older fallow. Run `npx fallow agent install` again, or update the plugin.
