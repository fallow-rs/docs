With the fallow skills installed, your coding agent runs the right fallow command for a request and reads the output correctly. It does not guess from general knowledge. The skills tell the agent:

- when to run each command
- which flags to use
- how to read the output
- how to avoid common pitfalls

They cover codebase health, cleanup analysis, circular dependencies, duplication, and complexity hotspots.

<Info>
  Skills work together with the CLI and MCP integrations. Skills tell the agent *how* to use fallow. The CLI and MCP give the agent the *tools*.
</Info>

## What's included

The [fallow-skills](https://github.com/fallow-rs/fallow-skills) package includes:

| Component | Description |
|:----------|:------------|
| **Analysis skill** | Workflows for unused code, duplication, complexity, boundary analysis, auto-fix, and CI setup |
| **CLI reference** | Commands, flags, output formats, and configuration |
| **Gotchas** | Common pitfalls with correct and incorrect examples, for example `fix --yes` in non-TTY |
| **Workflow patterns** | Recipes for CI pipelines, monorepo analysis, migrating from knip/jscpd, and incremental adoption |

## Installation

<Tip>
  If your project already has fallow installed from npm, you can skip the manual steps. [`fallow agent install`](/cli/agent) writes the skill where Claude Code, Codex, and Cursor look for it. It also writes the MCP registration, an `AGENTS.md` task map, and the commit and push gate. Add `--dry-run` to see the plan first.
</Tip>

<Tabs>
  <Tab title="Claude Code">
    ```bash
    /plugin marketplace add fallow-rs/fallow-skills
    /plugin install fallow@fallow-skills
    ```
  </Tab>
  <Tab title="Cursor">

  </Tab>
  <Tab title="OpenAI Codex">

The skills follow the open [Agent Skills](https://agentskills.io) specification, so any compatible agent can use them.

## What agents can do after installation

After you install the skills, your agent can handle requests like these:

<CardGroup cols={2}>
  <Card title="Find cleanup opportunities" icon="broom">
    "Find all unused exports in this project". The agent runs `fallow dead-code --format json --quiet --unused-exports` and summarizes the findings.
  </Card>
  <Card title="Clean up dependencies" icon="box-open">
    "Are there any unused dependencies?" The agent runs a targeted analysis and suggests removals.
  </Card>
  <Card title="Detect duplication" icon="copy">
    "Find code duplication in the codebase". The agent runs `fallow dupes` with the right mode and explains the clone families.
  </Card>
  <Card title="Auto-fix" icon="wrench">
    "Remove unused exports". The agent does a dry run first and shows the proposed changes. Then it applies them with `--yes`.
  </Card>
  <Card title="CI setup" icon="shield-check">
    "Set up a code quality gate in CI". The agent writes a GitHub Actions workflow with baselines.
  </Card>
  <Card title="Debug false positives" icon="bug">
    "Why is this export flagged?" The agent uses `--trace` to find the cause and suggests a suppression if needed.
  </Card>
</CardGroup>

## Skills vs MCP vs CLI

| | Skills | MCP | CLI |
|:--|:-------|:----|:----|
| **What it provides** | Knowledge about *how* to use fallow | Structured tool interface | Direct command execution |
| **Setup** | One-time install per agent | MCP server configuration | Fallow binary in PATH |
| **Agent support** | Any agent with skill support | Agents with MCP support | Any agent that runs shell commands |
| **Best for** | Teaching agents how to use fallow | Typed tool calling in agent frameworks | Any environment with a shell |

<Tip>
  Use all three together. Install the skill so the agent knows how to use fallow. Configure MCP for typed tool calls. Keep fallow in PATH as a CLI fallback.
</Tip>
