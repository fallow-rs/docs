Fallow finds circular dependencies and draws the import graph, like madge. This guide maps each madge command to a fallow command. `fallow migrate` does not read a madge config. Fallow finds the [entry points](/concepts/entry-points) and the `tsconfig.json` path aliases itself, so you do not give it a source directory.

## Before you start

- The madge commands that your scripts and your CI run.

## What maps to what

| madge | fallow |
|:--|:--|
| `madge --circular src/` | `fallow architecture --cycles` |
| `madge --orphans src/` | `fallow dead-code --unused-files`. See [What differs](#what-differs). |
| `madge --depends <module> src/` | `fallow dead-code --trace-file <path>`, the list of importers |
| `madge --dot src/` | `fallow viz --viz-format dot` |
| `madge --image graph.svg src/` | `fallow viz --viz-format dot \| dot -Tsvg -o graph.svg` |
| `madge --warning` | [`unresolved-import`](/rules/unresolved-import) findings |
| `madge --leaves`, `madge --json` | No fallow command. |

To find the shortest chain of imports between two files, run `fallow trace --path <from> <to>`.

## Steps

1. Replace the cycle check of your CI:

   ```bash
   npx fallow architecture --cycles
   ```

   The command exits with code 1 when it finds a cycle, because `circular-dependency` has the default severity `error`.

2. Replace each other madge command with the command of the table.

## Check the result

Run `fallow architecture --cycles` on a commit where madge found a cycle. Fallow does not report a cycle of `import type` imports, because such a cycle cannot fail at run time.

## What differs

- madge reports an orphan when no module imports it. Fallow reports an unused file when no entry point reaches it. So fallow does not report an entry point that nothing imports, and it reports a group of files that only import each other.
- Fallow reads JavaScript and TypeScript, and the imports of Vue, Svelte, Astro, MDX and HTML files. See [File types](/guides/file-types).
- The default output of `fallow viz` is an interactive HTML map. DOT and Mermaid output need a separate tool to make an image.

## Run both tools for a while

You can run both tools in CI until the cycle lists agree, then remove madge. To start on a project with existing cycles, save a [baseline](/guides/baselines).
