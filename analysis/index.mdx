Fallow shows you which code is unused, repeated, too complex, or in the wrong layer, and which code production actually runs. It works at two levels:

- **Static intelligence**: structure, reachability, duplication, complexity, boundaries, and flags.
- **Runtime intelligence**: the code that executed in production.
