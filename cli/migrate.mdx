Convert the config of knip, jscpd or stylelint into a fallow [config file](/configuration/overview).

For each source tool, read the migration page: [knip](/migration/from-knip), [jscpd](/migration/from-jscpd) or [stylelint](/migration/from-stylelint).

## Options

{/* generated:start cli-options migrate */}

| Option | Description |
|:--|:--|
| `--toml` | Generate `fallow.toml` instead of JSONC |
| `--jsonc` | Write JSONC content to `.fallowrc.jsonc` instead of `.fallowrc.json`. The generated content is the same JSONC (with `//` comments) either way; the `.jsonc` extension lets editors auto-detect JSON-with-comments syntax highlighting and silences linters that flag comments in `.json`. |
| `--dry-run` | Only preview the generated config without writing |
| `--from <PATH>` | Path to source config file (auto-detect if not specified) |

The [global options](/cli/global-flags) are in these groups: [Project](/cli/global-flags#options-project), [Output](/cli/global-flags#options-output), [Scope](/cli/global-flags#options-scope), [Baselines](/cli/global-flags#options-baselines), [Gates](/cli/global-flags#options-gates), [Duplication](/cli/global-flags#options-duplication), [Type-aware](/cli/global-flags#options-type-aware), [Performance](/cli/global-flags#options-performance).

`--toml` and `--jsonc` exclude each other. Without `--from`, fallow reads these sources and merges them into one config file:

| Tool | Sources |
|:--|:--|
| knip | `knip.json`, `knip.jsonc`, `.knip.json`, `.knip.jsonc`, the `knip` field of `package.json` |
| jscpd | `.jscpd.json`, the `jscpd` field of `package.json` |
| stylelint | `.stylelintrc`, `.stylelintrc.json`, `.stylelintrc.jsonc`, `stylelint.config.js`, `stylelint.config.cjs`, `stylelint.config.mjs`, the `stylelint` field of `package.json` |

Fallow finds `knip.ts` and `knip.config.ts`, but cannot read them. Convert such a file to `knip.json` first. Fallow converts only the settings that have a fallow equivalent, and prints a note for each setting that it does not convert.

### knip conversions {#knip-conversions}

- knip reads an `ignoreDependencies` entry as a regular expression when it is written as `/.../` or holds one of `* + \ ( | { ^ $`. Fallow converts the entry to a glob only when a glob matches the same package names, for example `^@types/.*$` to `@types/*`. Fallow skips each other entry with a warning.
- Fallow merges the settings of each knip `workspaces` entry into the top level, with the workspace path in front of each pattern. For example, `src/x.ts` of `packages/*` becomes `packages/*/src/x.ts`.
- An unknown key in `rules` gives the warning ``unknown knip issue type `<name>`; not migrated``.

This sample comes from a `knip.json` with these three cases:

```text
Warnings (3):
  [knip] `ignoreDependencies`: regex pattern `eslint-.+` skipped (no glob matches the same names) (suggestion: rewrite it as a glob such as `@scope/*`, or add each name)
  [knip] `ignoreDependencies`: regex pattern `/^(a|b)$/` skipped (no glob matches the same names) (suggestion: rewrite it as a glob such as `@scope/*`, or add each name)
  [knip] `rules.bogus`: unknown knip issue type `bogus`; not migrated (suggestion: check for a typo or report the missing mapping at https://fallow.tools/docs/migration/from-knip/)
```

## Output

```bash
fallow migrate --dry-run
```

```text
{
  "$schema": "https://raw.githubusercontent.com/fallow-rs/fallow/main/schema.json",
  // Migrated from knip.json
  "entry": [
    "src/index.ts",
    "scripts/*.js"
  ],
  "ignoreFindings": [
    "src/utils/legacy-*.ts"
  ],
  "ignoreDependencies": [
    "left-pad"
  ],
  "ignoreExportsUsedInFile": true,
  "rules": {
    "unused-exports": "warn"
  }
}

Migrated from: knip.json

Note: knip and fallow use different glob engines; verify migrated entry /
ignoreFindings with `fallow dead-code` before relying on CI.
https://fallow.tools/docs/migration/from-knip/
```

With `--dry-run`, fallow prints the new config file. Without it, fallow writes the file and prints `Created .fallowrc.json`. The `Migrated from:` line names the sources, and each `Note:` explains a difference that needs a check.

## Exit codes

| Code | Meaning |
|:--|:--|
| `0` | Fallow converted the config. |
| `2` | No source config, a fallow config file that exists already, or a source that fallow cannot read. |

See [Exit codes](/reference/exit-codes).

## Examples

```bash
# Show the converted config, and write nothing
fallow migrate --dry-run

# Convert each source that fallow finds
fallow migrate

# Convert one file into fallow.toml
fallow migrate --from config/knip.json --toml
```
