Write an interactive HTML map of the project and its findings, or write the import graph as text.

## Synopsis

{/* generated:start cli-synopsis viz */}

```bash
fallow viz [OPTIONS]
```

{/* generated:end */}

## Options

{/* generated:start cli-options viz */}

| Option | Default | Description |
|:--|:--|:--|
| `--out <PATH>` |  | Output file path (default: fallow-viz.html in project root) |
| `--no-open` |  | Don't open the output file in the browser |
| `--viz-format <VIZ_FORMAT>` | `html` | Visualization output format. Values: `html`, `dot`, `mermaid`. |

{/* generated:end */}

`--viz-format dot` and `--viz-format mermaid` print the import graph to stdout and write no HTML file. The [global options](/cli/global-flags) apply, for example `--production`, `--workspace` and `--changed-since`.

## Output

```bash
fallow viz --no-open
```

```text
Visualization generated in 43ms (16 files, 6 findings)
```

A second line gives the absolute path of the file. The HTML file needs no server and loads no external files. It has two views of the project: a treemap of the files by size, and a graph of the imports. Four lenses color both views: dead code, duplication, architecture boundaries and complexity. A click on a file opens the evidence of each finding and the `fallow` command that confirms it.

```bash
fallow viz --viz-format mermaid
```

```text
graph LR
  n0["scripts/seed-data.js"]
  n1["scripts/seed.js"]
  n2["src/index.ts"]
```

## Examples

```bash
# Write fallow-viz.html and open it in the browser
fallow viz

# Write the map to another file, and do not open it
fallow viz --out map.html --no-open

# Render the import graph as SVG with Graphviz
fallow viz --viz-format dot | dot -Tsvg -o graph.svg

# Save the import graph as a Mermaid diagram
fallow viz --viz-format mermaid > graph.mmd
```
