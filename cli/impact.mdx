Show a local report of the findings that fallow reports, the commits that a gate blocked until a fix, and the findings that went away.

Impact is off until you turn it on. Fallow keeps the history in your user config directory, never in the repository, and uploads nothing. Fallow does not record in CI, or for a project in a system temp directory. Recording never changes an exit code or the output of an analysis.

## Options

{/* generated:start cli-options impact */}

| Option | Default | Description |
|:--|:--|:--|
| `--all` |  | Aggregate every tracked project into one cross-repo roll-up ("what has fallow done for me across all my repos"). Reads the user config dir; ignores `--root`. |
| `--sort <SORT>` | `recent` | Row ordering for `--all` (default: most recently recorded first). Values: `recent`, `resolved`, `contained`, `name`. |
| `--limit <LIMIT>` |  | Cap the number of `--all` rows printed (grand totals still reflect every tracked project) |

{/* generated:end */}

`--all` works from any directory, also outside a repository, because it reads only the stored histories.

## Output

```bash
fallow impact
```

```text
FALLOW IMPACT

  LATEST RUN (changed files, act on these now)
    0 issues flagged in your last `fallow audit` run
      dead code 0  ·  complexity 0  ·  duplication 0

  WHOLE PROJECT (whole-repo context, not a to-do)
    8 issues across the whole project at your last full `fallow` run
    project trend starts after your next full `fallow` run
      advances only on your local full `fallow` runs, not CI

  CONTAINED AT COMMIT
    0 times fallow blocked a commit until it was fixed

  RESOLVED
    none yet; a finding is credited when fallow re-analyzes the
      file it left (a fix that reverts a file to its base state
      may not be individually credited)
```

| Part | Meaning |
|:--|:--|
| `LATEST RUN` | The findings of the last recorded `fallow audit` run. |
| `WHOLE PROJECT` | The findings of the last full `fallow` run, and the change since the run before it. |
| `CONTAINED AT COMMIT` | The number of times that a gate failed `fallow audit`, and a later run passed. The Git hook of [`fallow hooks`](/cli/hooks) and the agent gate mark these runs. |
| `RESOLVED` | Findings that went away because the code changed. A finding that a suppression comment hides counts as suppressed, not as resolved. |

```bash
fallow impact statusline
```

```text
fallow impact  8 issues in last full scan · compare after next full scan · 0 cleared while tracking
```

With `--format json`, `fallow impact` and `fallow impact status` print `kind: "impact"` with these top-level fields:

| Field | Content |
|:--|:--|
| `schema_version` | The version of this output format. |
| `enabled` | `true` when recording is on for this project. |
| `enabled_source` | Why recording is on or off: `project`, `user` (the global default) or `default` (off). |
| `explicit_decision` | `true` after an explicit `impact enable` or `impact disable`. |
| `onboarding_declined` | `true` after [`fallow init --decline`](/cli/init). |
| `record_count`, `first_recorded`, `latest_git_sha` | The size and the age of the history. |
| `surfacing`, `project_surfacing` | The finding counts of the last audit run and of the last full run. |
| `containment_count`, `recent_containment` | The commits that a gate blocked until a fix. |
| `resolved_total`, `suppressed_total`, `recent_resolved` | The findings that went away, and the findings that a suppression hid. |
| `attribution_active` | `true` when the history holds the data to credit a resolved finding. |

`fallow impact --all --format json` prints `kind: "impact-cross-repo"` with `projects` (one report and a `project_key` for each project), `totals`, `project_count`, `tracked_count` and `unreadable_count`. No report holds a file path. The [JSON output reference](/reference/json-output) has each field.

Fallow keeps one history file for each repository in `~/Library/Application Support/fallow/impact/` on macOS, `$XDG_CONFIG_HOME/fallow/impact/` on Linux and `%APPDATA%\fallow\impact\` on Windows. [`FALLOW_IMPACT_STORE_MAX_AGE_DAYS`](/configuration/environment) removes the history files that nobody used for that number of days.

## Exit codes

| Code | Meaning |
|:--|:--|
| `0` | The command completed. |
| `2` | Invalid input, or a history file that a newer fallow wrote. `enable` and `disable` then refuse to change it. |

See [Exit codes](/reference/exit-codes).

## Examples

```bash
# Record the runs of this project
fallow impact enable

# Record the runs of each project that has no setting of its own
fallow impact default on

# Show the report of this project
fallow impact

# Rank all projects by the number of resolved findings
fallow impact --all --sort resolved --limit 10

# Delete the history of each project
fallow impact reset --all
```
