Show the callers and callees of one exported symbol, the shortest import path between two modules, or how the code uses a package.

For a walk from a finding to its cause, read [Trace a finding](/guides/trace-a-finding).

## Synopsis

{/* generated:start cli-synopsis trace */}

```bash
fallow trace [OPTIONS] [FILE:SYMBOL]
```

{/* generated:end */}

## Options

{/* generated:start cli-options trace */}

| Argument | Description |
|:--|:--|
| `[FILE:SYMBOL]` | Target symbol, formatted as FILE:SYMBOL (e.g. src/utils.ts:formatDate). Omitted when `--path` or `--dependency` is used |

### Tracing {#options-tracing}

| Option | Description |
|:--|:--|
| `--dependency <PACKAGE>` | How the code uses each imported name of a package: file and call counts, one hop through project wrappers, and a count of each use that the trace cannot resolve. `--sites`, `--specifier`, `--limit` and `--cursor` page the usage sites. |
| `--path <FROM TO>` | Shortest import path between two modules, as two file paths (e.g. `--path src/app.ts src/db.ts`). Mutually exclusive with the symbol target and the call-chain flags |
| `--eager-only` | With `--path`, follow only static value imports, so the route explains why TO loads before FROM runs. `import()`, lazy globs, worker loads and `import type` do not qualify. |
| `--callers` | Walk up to callers (modules that import the symbol). When neither `--callers` nor `--callees` is set, both directions are walked |
| `--callees` | Walk down to callees (the symbol's module's import-symbol edges plus unresolved call sites). When neither flag is set, both are walked |
| `--depth <N>` | Chain depth bound for both directions (default 2). Symbol-level is best-effort, so a shallow bound keeps the trace legible |

### Scope {#options-scope}

| Option | Description |
|:--|:--|
| `--specifier <NAME>` | With `--dependency`, report only these imported names (repeatable or comma-separated). Turns on the site page |

### Output {#options-output}

| Option | Description |
|:--|:--|
| `--sites` | With `--dependency`, list the usage sites with file, line and column |
| `--limit <N>` | With `--dependency`, the largest number of sites on a page (1 to 500, default 50). Turns on the site page |
| `--cursor <TOKEN>` | With `--dependency`, the `next_cursor` of the previous page. Turns on the site page |

The [global options](/cli/global-flags) are in these groups: [Project](/cli/global-flags#options-project), [Output](/cli/global-flags#options-output), [Scope](/cli/global-flags#options-scope), [Baselines](/cli/global-flags#options-baselines), [Gates](/cli/global-flags#options-gates), [Duplication](/cli/global-flags#options-duplication), [Type-aware](/cli/global-flags#options-type-aware), [Performance](/cli/global-flags#options-performance).

`FILE` in the target is a path from the project root. When no file has the exact path, fallow accepts a path suffix and takes the first match. `--path` and `--dependency` replace the target. The walk is syntactic: fallow does not use the TypeScript type checker.

## Output

### Call chain {#call-chain}

```bash
fallow trace src/services/orders.ts:createOrder
```

```text
Symbol-level call chain (best-effort, syntactic; OFF the ranked path)

  symbol: src/services/orders.ts:createOrder
  found:  true
  depth:  2

Callers (up): 1
  [1] src/index.ts (imported as createOrder -> local createOrder)

Resolved callees (down): 1
  [1] src/services/catalog.ts (imported as lookupPrice -> local lookupPrice)

Unresolved callees (reported, not dropped): 0
```

Callers are the files that import the symbol. Resolved callees are the imports of the file of the symbol. An unresolved callee is a call that fallow cannot follow, for example `Math.round`. With `--format json`, the fields are `file`, `symbol`, `symbol_found`, `depth`, `callers`, `callees`, `unresolved_callees`, `best_effort` and `reason`. When two `export *` sources give the same name, `star_export_ambiguity` lists the `sources` and the `namespaces`.

### Import path between two modules {#import-path-between-two-modules}

```bash
fallow trace --path src/index.ts src/lib/format.ts
```

```text
Shortest import path (syntactic; OFF the ranked path)

  from:      src/index.ts
  to:        src/lib/format.ts
  reachable: yes
  hops:      2

  [1] src/index.ts:2 -> src/lib/index.ts
  [2] src/lib/index.ts:1 -> src/lib/format.ts
```

Each hop gives the importing file, the line of the import, and the imported file. A hop through `import()` or a worker has the tag `[dynamic]`. A pair without a path has `reachable: no`. That is a result, and the exit code stays `0`. With `--eager-only`, fallow follows only the static imports that load a value at startup. With `--format json`, the fields are `schema_version`, `from`, `to`, `reachable`, `hops`, `path` and `reason`. Each hop in `path` has `from`, `to`, `import_line`, `type_only` and `dynamic`.

### Usage of a package {#usage-of-a-package}

```bash
fallow trace --dependency zod
```

```text
  USED zod (1 import(s))

  Imported by:
    -> src/index.ts

  Usage by imported name (syntactic):
    NAME  FILES  TYPE-ONLY  CALLS  UNRESOLVED
    z         1          0      3  -
```

Each row gives one imported name: the number of files that import it, the files that import only its type, the calls, and the uses that fallow cannot follow. With `--format json`, the fields are `package_name`, `is_used`, `import_count`, `imported_by`, `type_only_imported_by`, `used_in_scripts` and `usage`. `usage` holds `specifiers`, `unresolved` and `confidence`, and `sites` with `next_cursor` when the site page is on.

Each mode has `kind: "trace"`. The [JSON output reference](/reference/json-output) has each field.

## Exit codes

| Code | Meaning |
|:--|:--|
| `0` | The trace completed, also when the symbol is not found or no import path exists. |
| `2` | Invalid input, for example a file that is not in the project, or a `--path` endpoint that matches more than one file. |

See [Exit codes](/reference/exit-codes).

## Examples

```bash
# Show the callers of a symbol, one level deep
fallow trace src/api.ts:fetchUser --callers --depth 1

# Show why one module imports another
fallow trace --path src/app.ts src/db.ts

# Show only the imports that load at startup
fallow trace --path src/app.ts src/db.ts --eager-only

# Show where the code calls one function of a package
fallow trace --dependency date-fns --specifier format --sites
```
