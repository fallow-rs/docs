Create a [config file](/configuration/overview) that fits the project, and optionally an `AGENTS.md` guide or a Git pre-commit hook.

For a first setup of fallow in a project, read [Adopt fallow](/guides/adopt).

## Synopsis

{/* generated:start cli-synopsis init */}

```bash
fallow init [OPTIONS]
```

## Options

{/* generated:start cli-options init */}

| Option | Description |
|:--|:--|
| `--toml` | Generate TOML instead of JSONC |
| `--agents` | Scaffold a starter AGENTS.md guidance file for coding agents |
| `--hooks` | Scaffold a shell-level pre-commit git hook in `.git/hooks/` that runs fallow on changed files. Alias for `fallow hooks install --target git` |
| `--decline` | Record that this project deliberately stays unconfigured: persists a decline so the first-contact setup hint and the `setup` next-step stop appearing here. Writes no config file; idempotent |

The [global options](/cli/global-flags) are in these groups: [Project](/cli/global-flags#options-project), [Output](/cli/global-flags#options-output), [Scope](/cli/global-flags#options-scope), [Baselines](/cli/global-flags#options-baselines), [Gates](/cli/global-flags#options-gates), [Duplication](/cli/global-flags#options-duplication), [Type-aware](/cli/global-flags#options-type-aware), [Performance](/cli/global-flags#options-performance).

Fallow detects TypeScript, the workspace patterns and the frameworks of the project, and writes the matching `entry` patterns and rules. Without `--toml`, the file is `.fallowrc.json` with JSONC content. Rename it to `.fallowrc.jsonc` to get editor support for comments. Fallow finds both names.

Fallow also adds `.fallow/` to `.gitignore`. That directory holds local data, for example the cache.

`--agents` writes a starter `AGENTS.md` with a table of agent tasks and their fallow commands. Fallow fills in the install, test and typecheck commands only when it can detect them without doubt. It does not change an existing `AGENTS.md`.

`--hooks` is the same as [`fallow hooks install --target git`](/cli/hooks#install).

`--decline` writes no file. It stops the setup hint that a bare `fallow` run shows in a project without a config file.

## Output

```bash
fallow init
```

```text
Created .fallowrc.json
  Detected: TypeScript
  Detected: Vitest
  Config includes test framework rules
Added .fallow/ to .gitignore
Next: run `fallow` for a first report. Run `fallow agent install --dry-run` to see the setup for coding agents.
```

The new file for this project:

```jsonc
{
  // This file is JSONC: fallow reads these comments; generic JSON tools may not.
  "$schema": "https://raw.githubusercontent.com/fallow-rs/fallow/main/schema.json",
  "entry": [
    "src/index.{ts,tsx,js,jsx}",
    "src/main.{ts,tsx,js,jsx}"
  ],
  "duplicates": {
    // Hide pair-only clones; focus on widespread copy-paste
    // worth refactoring. Lower to 2 to report every duplicate pair.
    "minOccurrences": 3
  },
  "rules": {
    "unused-dependencies": "warn"
  }
}
```

The real file also holds a commented example of `duplicates.ignore`. The `$schema` line gives completion and validation in the editor.

## Exit codes

| Code | Meaning |
|:--|:--|
| `0` | Fallow wrote the file. |
| `2` | A config file exists already, a target file is a symlink that leaves the project, or `--decline` meets a history file of [`fallow impact`](/cli/impact) that a newer fallow wrote. |

See [Exit codes](/reference/exit-codes).

## Examples

```bash
# Create .fallowrc.json
fallow init

# Create fallow.toml
fallow init --toml

# Create the config file and a starter AGENTS.md
fallow init --agents

# Create the config file and a Git pre-commit hook
fallow init --hooks

# Keep the project without a config file, and hide the setup hint
fallow init --decline
```
