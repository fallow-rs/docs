Watch mode re-runs dead code analysis when files change. Saves are debounced. Press `Ctrl+C` to stop.

```bash
fallow watch
```

<Info>
  Watch mode supports the [global flags](/cli/global-flags) (like `--format`, `--production`, `--fail-on-issues`, `--include-entry-exports`, `--type-aware`, and the `--dupes-*` family). The `dead-code` issue-type filters like `--unused-exports` are not available.
</Info>

## Examples

<CodeGroup>
```bash Filtered watch
# Production mode
fallow watch --production

# Compact output
fallow watch --format compact

# Silent, only show results
fallow watch --quiet
```
</CodeGroup>
