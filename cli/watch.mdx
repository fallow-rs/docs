Keep `fallow watch` open while you edit, and see new dead code as you save. Watch mode re-runs dead code analysis when files change. Fallow debounces saves. Press `Ctrl+C` to stop.

```bash
fallow watch
```

<Info>
  Watch mode supports the [global flags](/cli/global-flags), for example `--format`, `--production`, `--fail-on-issues`, `--include-entry-exports`, `--type-aware`, and the `--dupes-*` flags. The `dead-code` issue-type filters, such as `--unused-exports`, are not available.
</Info>

## Examples

<CodeGroup>
```bash Filtered watch
# Production mode
fallow watch --production

# Compact output
fallow watch --format compact

# Silent, only show results
fallow watch --quiet
```
</CodeGroup>

## Options

| Flag | Description |
|:-----|:------------|
| `--no-clear` | Do not clear the screen between runs. Fallow clears the screen only when stderr is a terminal. |

## Example output

Fallow runs the analysis one time at start. Then it runs the analysis again after each change:

```text title="$ fallow watch"
✓ No issues found (0.03s)

Watching for changes... (press Ctrl+C to stop)
Changed: src/db.ts

── Unused Code ─────────────────────────────────────

● Unused exports (1)
  src/db.ts
    :2 unusedThing

✗ 1 export (0.02s)

Watching for changes... (press Ctrl+C to stop)
```
