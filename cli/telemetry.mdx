Show, turn on and turn off the opt-in product telemetry, and print the payload that fallow sends. Telemetry is off by default.

For what fallow collects and what it never collects, read [Telemetry and privacy](/explanations/telemetry).

`FALLOW_TELEMETRY=inspect` before a command prints the payload of that command on stderr and sends nothing. The output of the command does not change.

## Options

The first setting that is present decides, in this order:

1. `DO_NOT_TRACK` or `FALLOW_TELEMETRY_DISABLED`: off. Each value turns telemetry off, except empty, `0`, `false`, `no` and `off`. So `DO_NOT_TRACK=yes` also works.
2. `FALLOW_TELEMETRY_DEBUG`: inspect mode.
3. `FALLOW_TELEMETRY`.
4. In CI: off, unless `FALLOW_TELEMETRY` is set.
5. The user config file of `fallow telemetry enable` or `disable`.
6. The default: off.

{/* generated:start environment-variables FALLOW_TELEMETRY */}

| Variable | Default | Description |
|:--|:--|:--|
| `FALLOW_TELEMETRY` | `off` | Opt-in telemetry mode: off, on, or inspect (print the payload to stderr without sending). Telemetry is off by default. |
| `FALLOW_TELEMETRY_DISABLED` |  | Admin/fleet kill switch: truthy values hard-disable telemetry and refuse fallow telemetry enable. |
| `FALLOW_TELEMETRY_DEBUG` |  | Truthy values alias `FALLOW_TELEMETRY`=inspect. |

{/* generated:end */}

### Agent source {#agent-source}

When telemetry is on, an agent can name itself in `FALLOW_AGENT_SOURCE`. The values are `codex`, `claude_code`, `cursor`, `copilot`, `opencode`, `aider`, `roo`, `windsurf`, `gemini`, `cline`, `continue`, `zed`, `goose`, `other_known`, `unknown` and `none`. Fallow ignores another value. `FALLOW_AGENT_SOURCE` never turns on telemetry.

## Output

```bash
fallow telemetry status
```

```text
Telemetry: off (default)
Install grouping token: none
Explicit decision: no
Enable:  fallow telemetry enable
Disable: fallow telemetry disable
Inspect an example: fallow telemetry inspect --example
Inspect a real command: FALLOW_TELEMETRY=inspect fallow audit --format json --quiet
```

The first line gives the state and, in parentheses, the setting that decided it. A `Config:` line gives the path of the user config file.

With `--format json`, `status` prints a `telemetry` object with `state`, `source`, `config_path`, `admin_disabled`, `explicit_decision`, `install_grouping_token`, `commands` and `docs`.

## Examples

```bash
# Show the state of telemetry
fallow telemetry status

# Turn off telemetry on this machine
fallow telemetry disable

# Print the payload of a command, and send nothing
FALLOW_TELEMETRY=inspect fallow audit --format json --quiet
```
