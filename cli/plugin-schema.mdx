Print the JSON Schema of an external [plugin](/concepts/plugins) file: a `fallow-plugin-*` file, a file in `.fallow/plugins/`, or a file that the `plugins` config key names.

For how to write a plugin, read [Custom plugins](/guides/custom-plugins).

## Synopsis

{/* generated:start cli-synopsis plugin-schema */}

```bash
fallow plugin-schema [OPTIONS]
```

{/* generated:end */}

## Options

This command has no options of its own. It reads no project and no config file. The output is JSON for each `--format`.

## Output

```bash
fallow plugin-schema | jq '{title, "$schema": ."$schema"}'
```

```text
{
  "title": "ExternalPluginDef",
  "$schema": "https://json-schema.org/draft/2020-12/schema"
}
```

The output is a JSON Schema (draft 2020-12) with each plugin key, for example `enablers`, `entryPoints` and `manifestEntries`. The npm package `fallow` does not hold this schema. To get completion in an editor, set the `$schema` key of a JSON plugin file to one of these values:

| Source | `$schema` value |
|:--|:--|
| A local file | The path of the file that `fallow plugin-schema > plugin-schema.json` wrote, relative to the plugin file. |
| The fallow repository | `https://raw.githubusercontent.com/fallow-rs/fallow/main/plugin-schema.json` |

The [MCP server](/integrations/mcp) serves the same schema as the resource `fallow://schema/plugin`.

## Exit codes

| Code | Meaning |
|:--|:--|
| `0` | Fallow printed the schema. |
| `2` | Invalid input, for example an unknown option. |

## Examples

```bash
# Save the schema next to the plugin files
fallow plugin-schema > .fallow/plugins/plugin-schema.json

# List the keys of a plugin file
fallow plugin-schema | jq '.properties | keys'
```
