Print the JSON Schema of the [config file](/configuration/overview): each key with its type, its default and its description.

For each config key, read the [Configuration reference](/reference/config).

## Synopsis

{/* generated:start cli-synopsis config-schema */}

```bash
fallow config-schema [OPTIONS]
```

{/* generated:end */}

## Options

This command has no options of its own. It reads no project and no config file. The output is JSON for each `--format`.

## Output

```bash
fallow config-schema | jq '{title, "$schema": ."$schema"}'
```

```text
{
  "title": "FallowConfig",
  "$schema": "https://json-schema.org/draft/2020-12/schema"
}
```

The output is a JSON Schema (draft 2020-12). It is the same file as `schema.json` in the npm package `fallow` of the same version. To get completion and validation in an editor, set the `$schema` key of a JSON config file to one of these values:

| Source | `$schema` value |
|:--|:--|
| The npm package | `./node_modules/fallow/schema.json` |
| The fallow repository | `https://raw.githubusercontent.com/fallow-rs/fallow/main/schema.json` |
| A local file | The path of the file that `fallow config-schema > schema.json` wrote. |

The [MCP server](/integrations/mcp) serves the same schema as the resource `fallow://schema/config`.

## Exit codes

| Code | Meaning |
|:--|:--|
| `0` | Fallow printed the schema. |
| `2` | Invalid input, for example an unknown option. |

## Examples

```bash
# Save the schema to a file
fallow config-schema > schema.json

# List the top-level config keys
fallow config-schema | jq '.properties | keys'
```
