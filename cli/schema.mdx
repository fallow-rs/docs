Print the capabilities of fallow as one JSON document: each command and option, each [issue type](/concepts/findings), each MCP tool, the built-in plugins and the environment variables.

## Synopsis

{/* generated:start cli-synopsis schema */}

```bash
fallow schema [OPTIONS]
```

{/* generated:end */}

## Options

{/* generated:start cli-options schema */}

| Option | Description |
|:--|:--|
| `--cli-reference` | Print the CLI reference instead of the capability manifest: every command and subcommand at each depth with its usage and full help, every option, the exit codes, the environment variables, the output formats and the explanation of each issue type |

The [global options](/cli/global-flags) are in these groups: [Project](/cli/global-flags#options-project), [Output](/cli/global-flags#options-output), [Scope](/cli/global-flags#options-scope), [Baselines](/cli/global-flags#options-baselines), [Gates](/cli/global-flags#options-gates), [Duplication](/cli/global-flags#options-duplication), [Type-aware](/cli/global-flags#options-type-aware), [Performance](/cli/global-flags#options-performance).

{/* generated:end */}

The output is JSON for each `--format`. Fallow reads the commands, the options and the plugins from the running build.

## Output

```bash
fallow schema | jq '{issue_types: (.issue_types | length), mcp_tools: (.mcp_tools.tools | length), plugins: .plugins.count}'
```

```text
{
  "issue_types": 136,
  "mcp_tools": 44,
  "plugins": 156
}
```

The output has these top-level fields:

| Field | Content |
|:--|:--|
| `manifest_version` | The version of this output format. |
| `name`, `version`, `description` | The name and the version of fallow. |
| `default_command`, `default_behavior` | What a bare `fallow` run does. `default_command` is `null`, because the bare run is not one command. |
| `commands`, `global_flags` | Each command and option, with its type, default and description. |
| `issue_types` | One object for each issue type, for example with `id`, `rule_id`, `config_key`, `default_severity`, `opt_in`, `command`, `category`, `filter_flag`, `fixable`, `suppress_comment` and `docs_url`. A field that does not apply is `null`. |
| `task_matrix` | Agent tasks with the read-only command for each. |
| `mcp_tools` | Each MCP tool in `tools`, with `name`, `kind`, `description`, `cli_command`, `key_params`, `license` and `read_only`. |
| `mcp_resources` | Each MCP resource in `resources`, with `uri`, `name`, `title`, `description`, `mime_type` and `template`. |
| `plugins` | The `count` and the names of the built-in plugins. |
| `environment_variables` | Each `FALLOW_*` variable with a description. |
| `boundary_presets` | The built-in boundary presets, each with the config line that turns it on. |
| `security_categories` | The valid ids for `security.categories`. |
| `taste_choices` | Setup choices for the user, each with the config keys that the answer sets. |
| `related_schemas` | The commands that print the other JSON Schemas. |
| `field_notes` | How to read the fields of `issue_types`. |
| `output_formats`, `exit_codes`, `severity_levels`, `suppression_comments` | The output formats, the exit codes, the severities and the suppression comments. |

The [MCP server](/integrations/mcp) is the authority for the full input schema of each tool.

## Exit codes

| Code | Meaning |
|:--|:--|
| `0` | Fallow printed the schema. |
| `2` | Invalid input, for example an unknown option. |

## Examples

```bash
# Print the suppression comment of one issue type
fallow schema | jq -r '.issue_types[] | select(.id == "unused-export") | .suppress_comment'

# List the issue types that fallow fix can fix
fallow schema | jq -r '.issue_types[] | select(.fixable) | .id'

# List the read-only MCP analysis tools
fallow schema | jq -r '.mcp_tools.tools[] | select(.read_only and .kind == "analysis") | .name'
```
