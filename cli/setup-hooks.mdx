Install or remove the commit gate, which blocks `git commit` and `git push` of a coding agent until `fallow audit` passes.

[Commit gate for Claude Code and Codex](/integrations/claude-hooks) explains the commit gate. This command is deprecated. Use [`fallow agent install`](/cli/agent) for the full agent setup, or [`fallow hooks install --target agent`](/cli/hooks#install) for the commit gate only.

```bash
fallow setup-hooks [OPTIONS]
```

## Options

{/* generated:start cli-options setup-hooks */}

| Option | Description |
|:--|:--|
| `--agent <AGENT>` | Target a specific agent surface (default: auto-detect). Values: `claude`, `codex`. |
| `--dry-run` | Print what would be written or removed without touching the filesystem |
| `--force` | Overwrite a user-edited hook script, invalid `settings.json`, or remove a user-edited script during uninstall |
| `--user` | Write to the user's home directory instead of the project root |
| `--gitignore-claude` | Append `.claude/` to the project's `.gitignore` |
| `--uninstall` | Remove the fallow-gate handler, hook script, and AGENTS.md managed block instead of installing them. Idempotent: reports "unchanged" when nothing to remove |

The [global options](/cli/global-flags) are in these groups: [Project](/cli/global-flags#options-project), [Output](/cli/global-flags#options-output), [Scope](/cli/global-flags#options-scope), [Baselines](/cli/global-flags#options-baselines), [Gates](/cli/global-flags#options-gates), [Duplication](/cli/global-flags#options-duplication), [Type-aware](/cli/global-flags#options-type-aware), [Performance](/cli/global-flags#options-performance).

## Examples

```bash
# Use this command in place of fallow setup-hooks
fallow hooks install --target agent

# Remove a gate that fallow setup-hooks installed
fallow hooks uninstall --target agent
```
