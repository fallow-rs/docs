Print what one [issue type](/concepts/findings) reports, why it matters, an example and the fix. Fallow runs no analysis.

Each issue type also has a page under [Issue types](/reference/issue-types).

## Synopsis

{/* generated:start cli-synopsis explain */}

```bash
fallow explain [OPTIONS] <ISSUE_TYPE>...
```

{/* generated:end */}

## Options

{/* generated:start cli-options explain */}

| Argument | Description |
|:--|:--|
| `<ISSUE_TYPE...>` | Issue type, issue label, or rule id to explain |

This command has no options of its own.

The [global options](/cli/global-flags) are in these groups: [Project](/cli/global-flags#options-project), [Output](/cli/global-flags#options-output), [Scope](/cli/global-flags#options-scope), [Baselines](/cli/global-flags#options-baselines), [Gates](/cli/global-flags#options-gates), [Duplication](/cli/global-flags#options-duplication), [Type-aware](/cli/global-flags#options-type-aware), [Performance](/cli/global-flags#options-performance).

Fallow accepts the issue type id (`unused-export`), the rule id (`fallow/unused-export`), the plural form (`unused-exports`) and the label (`unused exports`). Fallow joins more than one word into one label, so `fallow explain unused exports` works without quotes.

## Output

```bash
fallow explain unused-export
```

```text
Unused Exports
fallow/unused-export

Export is never imported

Why it matters
Named exports that are never imported by any other module in the project. Includes both direct exports and re-exports through barrel files. The export may still be used locally within the same file.

Example
export const formatPrice = ... exists in src/money.ts, but no module imports formatPrice.
```

The output also has a "How to fix" section and a link to the docs.

With `--format json`, the output has these top-level fields:

| Field | Content |
|:--|:--|
| `kind` | `"explain"` |
| `id` | The rule id, for example `fallow/unused-export`. |
| `name` | The name of the issue type. |
| `summary` | One line. |
| `rationale` | What the issue type reports, and why it matters. |
| `example` | A short example. |
| `how_to_fix` | The fix. |
| `docs` | The URL of the docs page. |

## Exit codes

| Code | Meaning |
|:--|:--|
| `0` | Fallow printed the explanation. |
| `2` | Fallow does not know the issue type. The message gives valid examples. |

See [Exit codes](/reference/exit-codes).

## Examples

```bash
# Explain one issue type
fallow explain unused-export

# Explain an issue type by its label
fallow explain code duplication

# Get the explanation as JSON for an agent
fallow explain fallow/high-complexity --format json --quiet
```
