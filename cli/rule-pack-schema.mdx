Print the JSON Schema of a rule pack file. A rule pack is a JSON or JSONC file of policy rules that the `rulePacks` config key names.

For the commands that write and test a rule pack, read [`fallow rule-pack`](/cli/rule-pack).

## Synopsis

{/* generated:start cli-synopsis rule-pack-schema */}

```bash
fallow rule-pack-schema [OPTIONS]
```

{/* generated:end */}

## Options

This command has no options of its own. It reads no project and no config file. The output is JSON for each `--format`. [`fallow rule-pack schema`](/cli/rule-pack#schema) prints the same schema.

## Output

```bash
fallow rule-pack-schema | jq '{title, "$schema": ."$schema"}'
```

```text
{
  "title": "RulePackDef",
  "$schema": "https://json-schema.org/draft/2020-12/schema"
}
```

The output is a JSON Schema (draft 2020-12) with the keys of a pack and each rule kind, for example `banned-import` and `banned-call`. It is the same file as `rule-pack-schema.json` in the npm package `fallow` of the same version. To get completion in an editor, set the `$schema` key of the pack file to one of these values:

| Source | `$schema` value |
|:--|:--|
| The npm package | The path of `node_modules/fallow/rule-pack-schema.json`, relative to the pack file. |
| The fallow repository | `https://raw.githubusercontent.com/fallow-rs/fallow/main/rule-pack-schema.json`. [`fallow rule-pack init`](/cli/rule-pack#init) writes this value. |
| A local file | The path of the file that `fallow rule-pack-schema > rule-pack-schema.json` wrote. |

The [MCP server](/integrations/mcp) serves the same schema as the resource `fallow://schema/rule-pack`.

## Exit codes

| Code | Meaning |
|:--|:--|
| `0` | Fallow printed the schema. |
| `2` | Invalid input, for example an unknown option. |

## Examples

```bash
# Save the schema to a file
fallow rule-pack-schema > rule-pack-schema.json

# List the rule kinds
fallow rule-pack-schema | jq -r '."$defs".RulePackRuleKind | .. | .const? // empty'
```
