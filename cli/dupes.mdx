`fallow dupes` finds code blocks that exist in more than one place.

For the concepts and the workflow, read [Duplication](/analysis/duplication).

## Synopsis

## Options

{/* generated:start cli-options dupes */}

| Argument | Description |
|:--|:--|
| `[PATH]` | Scope reported findings to this file or directory (default: whole project). The full project graph is still built; only reported items are narrowed |

### Detection {#options-detection}

| Option | Description |
|:--|:--|
| `--mode <MODE>` | Detection mode: strict, mild, weak, or semantic (defaults to the value in the config file, or `mild` if unset) |
| `--near` | Enable function-scoped near-miss clone detection |
| `--min-tokens <MIN_TOKENS>` | Minimum token count for a clone (defaults to the value in the config file, or `50` if unset) |
| `--min-lines <MIN_LINES>` | Minimum line count for a clone (defaults to the value in the config file, or `5` if unset) |
| `--min-occurrences <MIN_OCCURRENCES>` | Minimum number of occurrences before a clone group is reported. Raise to focus on widespread copy-paste worth refactoring and skip pair-only clones. (defaults to the value in the config file, or `2` if unset) |
| `--skip-local` | Only report cross-directory duplicates |
| `--cross-language` | Enable cross-language detection (strip TS type annotations for TS↔JS matching) |
| `--ignore-imports`, `--no-ignore-imports` | Exclude module wiring from clone detection (default; covers imports, re-exports, and top-level static require bindings). Pass `--no-ignore-imports` to count it again |
| `--ignore-symlinks`, `--no-ignore-symlinks` | Omit clone instances whose path is a symlink, or lies under a symlinked directory. A clone group with fewer than two remaining instances is not reported. |

### Output {#options-output}

| Option | Description |
|:--|:--|
| `--top <TOP>` | Show only the N highest-ranked clone groups. Ranking combines clone size, occurrence count, and capped directory or line spread. |
| `--no-fragments` | Omit the verbatim source text from each clone instance in `--format json`. The file and line/column range still address the same code, and this is most of the payload on a duplicated codebase |
| `--trace <FILE:LINE\|dup:<fingerprint>>` | Trace the clones at a location (`FILE:LINE`, for example `src/utils.ts:42`) or the clone group of a fingerprint (`dup:<fingerprint>`, for example `dup:f42424e8`) |

The detection options and `--threshold` take their default from the [`duplicates` config](/reference/config-duplication#duplicates). A flag overrides the config value for one run.

### Detection modes {#detection-modes}

| Mode | What fallow ignores when it compares code |
|:--|:--|
| `strict` | Nothing. The tokens must be the same. |
| `mild` | The default. It gives the same result as `strict`, because the token stream has no whitespace and no comments. |
| `weak` | The values of string literals. |
| `semantic` | The names of identifiers, and the values of string and number literals. |

### Normalization overrides {#normalization-overrides}

The keys of `duplicates.normalization` turn one part of the comparison on or off, whatever the mode is. A key that is not set takes the value of the mode.

| Key | Effect when `true` | On by default in |
|:--|:--|:--|
| `ignoreIdentifiers` | Fallow ignores the names of identifiers. | `semantic` |
| `ignoreStringValues` | Fallow ignores the values of string literals. | `weak`, `semantic` |
| `ignoreNumericValues` | Fallow ignores the values of number literals. | `semantic` |
| `consistentIdentifiers` | The names of two instances must map one to one, so `a = b + c` matches `x = y + z` but not `x = x + x`. It has an effect only with `ignoreIdentifiers`. | No mode |

The [configuration reference](/reference/config-duplication#duplicates-normalization) has the type of each key.

### Notes on options

- `--trace` also accepts a [handle](/analysis/duplication), for example `fallow dupes --trace dup:f42424e8`. The trace shows each instance, an extract-function suggestion and the code fragment.
- `--top` ranks a clone group by its token count times its instance count, with a boost of at most 15 percent for the spread. The spread is the largest directory distance between two instances. In one file, each 250 lines between instances count as one step.
- `--top` and `--group-by` together exit with code 2. With `--group-by`, fallow puts each clone group in the group that holds most of its instances.
- With `--ignore-symlinks`, the file totals and the percentage that `--threshold` checks count only real files. Without it, the human output marks a symlinked instance with `(symlink)`, and the JSON output sets `is_symlink: true` on it.
- By default, fallow adds these patterns to `duplicates.ignore`: `**/.next/**`, `**/.nuxt/**`, `**/.svelte-kit/**`, `**/.turbo/**`, `**/.parcel-cache/**`, `**/.vite/**`, `**/.cache/**`, `**/out/**`, `**/storybook-static/**`, `**/*.test.*`, `**/*.spec.*`, `**/__tests__/**` and `**/__mocks__/**`. The [`duplicates.ignoreDefaults`](/reference/config-duplication#duplicates-ignoredefaults) key turns this off. `--explain-skipped` lists the skipped files for each pattern.
- `--no-cache` turns off the token cache for one run. The token cache is on only for a project with at least `duplicates.minCorpusSizeForTokenCache` source files (default `5000`). Fallow stores it in `.fallow/cache/dupes-tokens-v<N>/`, with a `.gitignore` file that ignores the folder.

### Handles {#handles}

A handle has the form `dup:<8 hex digits>`, for example `dup:f42424e8`. When two clone groups of one report have the same 8 digits, fallow gives only these groups 16 digits (`dup:<16 hex digits>`). When two groups also have the same 16 digits, each gets a suffix `-r<N>`. An entry of `duplicates.ignoredClones` is a handle and an instance count, for example `dup:f42424e8:2`. A change of the tokens or of the instance count makes the group reportable again.

## Output

```text
note: skipped 1 file matching default duplicates ignores
  (--explain-skipped for the list)
note: module wiring excluded from clones
  (--no-ignore-imports to include it)

● Duplicates (1 clone groups)

     17 lines  2 instances  spread 2  dup:f42424e8
    src/reports/export.ts:3-19
    src/utils/summary.ts:7-23

  Duplicate code blocks
  https://fallow.tools/docs/explanations/duplication/#clone-groups

⚠ 34 lines (20.0%) duplicated across 2 files (0.01s)
```

- The `note:` lines name the files and the code that the run did not compare.
- Each clone group shows its line count, its instance count, its spread and its handle. One line for each instance gives the file and the line range.
- The last line gives the duplicated lines, the duplication percentage and the run time.

With `--format json`, the output has these top-level fields:

| Field | Content |
|:--|:--|
| `kind` | `"dupes"` |
| `schema_version` | The version of this output format. |
| `version` | The fallow version. |
| `elapsed_ms` | The run time in milliseconds. |
| `clone_groups` | One object for each clone group: `instances`, `token_count`, `line_count`, `fingerprint`, `spread`, `suggested_name`, `actions`. |
| `clone_families` | One object for each set of files that share clone groups. |
| `stats` | The totals of all compared code: files, lines, tokens, clone groups, clone families, instances and `duplication_percentage`. `--top` does not change these totals. `clone_groups_ignored` counts the groups that `duplicates.ignoredClones` hides. |
| `clone_groups_shown`, `clone_groups_omitted` | The number of groups in `clone_groups`, and the number that `--top` left out. Together they are `stats.clone_groups`. |
| `clone_families_shown`, `clone_families_omitted` | The same counts for `clone_families`. |
| `mirrored_directories` | Pairs of directories that hold the same files. Present only when fallow finds one. |
| `range_marker_problems` | `fallow-ignore-start` and `fallow-ignore-end` markers that have no effect, with the reason. Present only when fallow finds one. |
| `grouped_by`, `groups`, `total_issues` | The groups of a `--group-by` run. Present only in that run. |
| `baseline_staleness` | The entries of the loaded baseline that matched no clone group. Present only with `--baseline`. |
| `gate_outcomes` | One entry for each gate that the run set. Absent when the run set no gate. |
| `request_outcomes` | The result of each scope request. See [Request outcomes](/cli/global-flags#request-outcomes). |
| `next_steps` | Commands to run next. |
| `package_baselines` | The Git ref that each workspace package used as its base. Absent when no package base applies. |
| `workspace_diagnostics` | Problems with the project setup. Optional. |
| `_meta` | Metadata of the run, for example `telemetry.analysis_run_id`. |

Each instance has `file`, `start_line`, `end_line`, `start_col`, `end_col` and `fragment`. The lines are 1-based. The columns are 0-based byte offsets. `--no-fragments` leaves out `fragment`. The `fingerprint` field holds the handle.

Each clone group has an `actions` array with `extract-shared`, `suppress-line` and `suppress-range`. Each action has `auto_fixable: false`. The `suppress-range` action has the start marker in `comment` and the end marker in `end_comment`. The [JSON output reference](/reference/json-output) has each field.

## Exit codes

Without a gate, `fallow dupes` exits with code `0`, also when it finds clone groups.

| Code | Meaning |
|:--|:--|
| `0` | No gate failed. |
| `1` | A gate failed: `--fail-on-issues` or `--ci` (gate `duplication-findings`), `--threshold` (gate `duplication-threshold`), `--fail-on-stale-baseline` or `--fail-on-baseline-growth`. |
| `2` | Invalid input, for example `--top` together with `--group-by`. |

[Exit codes](/reference/exit-codes) has the codes that all commands share.

## Examples

```bash
# Also match copies that use other variable names
fallow dupes --mode semantic

# Show only the 10 highest-ranked clone groups
fallow dupes --top 10

# Show one clone group and its code
fallow dupes --trace dup:f42424e8

# Fail when more than 5 percent of the lines are duplicated
fallow dupes --threshold 5

# Report only the clone groups with an instance in a changed file
fallow dupes --changed-since main

# Save the current clone groups, then fail only on new groups
fallow dupes --save-baseline fallow-baselines/dupes.json
fallow dupes --baseline fallow-baselines/dupes.json --fail-on-issues
```
