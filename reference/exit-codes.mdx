Each fallow command exits with one of these codes. [Findings](/concepts/findings) explains the gates that set code 1.

## Shared exit codes {#shared-exit-codes}

| Code | Name | Meaning |
|:--|:--|:--|
| `0` | `success` | Success: no enforced gate failed. Bare fallow in a machine format (json, sarif, codeclimate, the GitHub formats, the comment and review formats) does not enforce findings without `--fail-on-issues`, so it exits 0 on findings. Read gate_outcomes: status "fail" with enforced false is a failing gate that did not set the exit code. |
| `1` | `gate-failed` | An enforced gate failed, for example error-severity findings (per rules config, or `--fail-on-issues` promotes warn to error). This is an analysis result, not a tool failure. |
| `2` | `invalid-input` | Invalid input or an execution error, for example an invalid config. With `--format` json, fallow writes the error to stdout as a JSON object with error true, a message and the exit_code. |
| `3` | `resource-unavailable` | Requested resource unavailable: config `--path` found no config, or a license is missing, invalid, or beyond its offline hard-fail window. |
| `4` | `runtime-coverage-sidecar` | The runtime coverage add-on is unavailable, unverifiable, protocol-incompatible, or stopped unexpectedly. |
| `5` | `runtime-coverage-input` | Runtime coverage input could not be prepared or parsed. |
| `6` | `runtime-coverage-internal` | The runtime coverage add-on reported an internal error. |
| `7` | `network-failure` | Network or cloud request failed during a license, coverage, or CI operation. |
| `8` | `security-gate` | Security gate matched a candidate selected by `--gate`. |
| `10` | `coverage-upload-validation` | Coverage inventory or static-findings upload input or project validation failed. |
| `11` | `coverage-upload-payload-too-large` | Coverage inventory or static-findings upload exceeded the server payload limit. |
| `12` | `coverage-upload-auth-rejected` | Coverage inventory or static-findings upload authentication or authorization was rejected. |
| `13` | `coverage-upload-server-error` | Coverage inventory or static-findings upload got a server error (5xx), a timeout (408), a rate limit (429), or a response that fallow cannot read. |

## Exit codes of one command {#command-exit-codes}
