## What it reports

Catalogue security candidate for CWE-1321.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

A key such as `__proto__` in the input changes the prototype of all objects. Checks elsewhere in the process can then read values that an attacker set.

## Example

`_.merge(settings, req.body);`

```ts title="src/server.ts"
import express from "express";
import _ from "lodash";

const app = express();
const settings = { currency: "EUR", taxRate: 21 };
app.use(express.json());

app.post("/settings", (req, res) => {
  _.merge(settings, req.body);
  res.json(settings);
});

app.listen(3000);
```

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
