## What it reports

Catalogue security candidate for CWE-502.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

The parser can create objects or run code from the input. An attacker who controls the input can then run code in the process. Check the trace before you fix.

## Example

`yaml.load(req.body.config);`

```ts title="src/server.ts"
import express from "express";
import yaml from "js-yaml";

const app = express();
app.use(express.json());

app.post("/shop/config", (req, res) => {
  const config = yaml.load(req.body.config);
  res.json(config);
});

app.listen(3000);
```

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
