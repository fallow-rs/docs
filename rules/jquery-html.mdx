## What it reports

Catalogue security candidate for CWE-79.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

jQuery parses the string as HTML and runs its scripts. If an attacker controls it, their script runs in the page. Check the trace before you fix.

## Example

`$('#preview').html(comment.body);`

```ts title="src/preview.ts"
import $ from "jquery";

interface Comment {
  body: string;
}

export const showPreview = (comment: Comment): void => {
  $("#preview").html(comment.body);
};
```

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
