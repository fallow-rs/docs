## What it reports

Catalogue security candidate for CWE-942.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

The policy allows every origin to send credentialed requests. Any website that a signed-in user visits can then call the API as that user.

## Example

`app.use(cors({ origin: '*', credentials: true }));`

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
