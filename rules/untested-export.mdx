## What it reports

Runtime-reachable export has no test dependency path.

[Health](/analysis/health) explains how fallow finds it.

## Why it matters

A value export is reachable from runtime entry points but no test-reachable module references it. This is a static test dependency gap rather than line coverage, and highlights exports exercised only through production entry paths.

## Example

Production-reachable code has no dependency path from discovered test entry points.

## Fix

Add or wire a test that imports the runtime path, or update entry-point/test discovery if the existing test is invisible to fallow.
