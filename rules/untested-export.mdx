## What it reports

Runtime-reachable export has no test dependency path.

[Health](/analysis/health) explains how fallow finds it.

## Why it matters

No test reaches the export. A change to its behavior can break the production code that uses it, and no test fails.

## Example

`src/cart.ts` calls `roundCents` from `src/money.ts`. `test/money.test.ts` imports only `formatPrice` from that file, so no test reaches `roundCents`.

```json title=".fallowrc.json"
{
  "rules": {
    "coverage-gaps": "warn"
  }
}
```

```ts title="src/cart.ts"
import { formatPrice, roundCents } from "./money";

const total = roundCents(19.999);
console.log(formatPrice(total));
```

```ts title="src/money.ts"
export const roundCents = (amount: number): number => Math.round(amount * 100) / 100;

export const formatPrice = (amount: number): string => `EUR ${amount.toFixed(2)}`;
```

```ts title="test/money.test.ts"
import { expect, it } from "vitest";
import { formatPrice } from "../src/money";

it("formats a price", () => {
  expect(formatPrice(5)).toBe("EUR 5.00");
});
```

## Fix

Add or wire a test that imports the runtime path, or update entry-point/test discovery if the existing test is invisible to fallow.
