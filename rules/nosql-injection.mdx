## What it reports

Catalogue security candidate for CWE-943.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

The query filter comes from the input as a whole object. An attacker can send an operator such as `$ne` and match records that they must not see, for example to skip a password check.

## Example

`users.findOne(req.body);`

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
