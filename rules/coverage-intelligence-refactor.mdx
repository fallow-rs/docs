## What it reports

Hot covered code has high CRAP and should be refactored carefully.

[Runtime coverage](/analysis/runtime-coverage) explains how fallow finds it.

## Why it matters

Coverage intelligence found hot production code that is covered by tests but still has high CRAP. Refactor carefully while preserving behavior.

## Example

`calculateTax` runs often in production and has 70% or more test coverage, but its CRAP score is above the limit.

## Fix

Refactor the function in small steps, and run the tests after each step.
