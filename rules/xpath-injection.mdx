## What it reports

Catalogue security candidate for CWE-643.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

The XPath engine parses the string as a query. An attacker who controls part of it can select other nodes, for example to skip a login check.

## Example

`xpath.select("//user[name='" + req.query.name + "']", doc);`

```ts title="src/server.ts"
import { DOMParser } from "@xmldom/xmldom";
import express from "express";
import xpath from "xpath";

const app = express();
const doc = new DOMParser().parseFromString("<users><user name='guest'/></users>", "text/xml");

app.get("/users", (req, res) => {
  const nodes = xpath.select("//user[name='" + req.query.name + "']", doc);
  res.json({ found: Array.isArray(nodes) && nodes.length > 0 });
});

app.listen(3000);
```

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
