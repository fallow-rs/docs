## What it reports

Catalogue security candidate for CWE-614.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

Without `httpOnly`, a script in the page can read the cookie. Without `secure`, the browser also sends it over plain HTTP, where others on the network can read it.

## Example

`res.cookie('session', id, { httpOnly: false });`

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
