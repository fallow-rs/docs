## What it reports

Catalogue security candidate for CWE-113.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

A value with line breaks can add headers or split the response. An attacker can then set cookies or change the response that the client gets.

## Example

`res.setHeader('Location', req.query.next);`

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
