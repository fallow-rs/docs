## What it reports

Catalogue security candidate for CWE-22.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

A path segment that contains `../` can point outside the intended directory. An attacker can then read or write other files on the server. Check the trace before you fix.

## Example

`fs.readFile(path.join(uploadDir, req.params.name));`

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
