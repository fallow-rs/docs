## What it reports

Catalogue security candidate for CWE-1427.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

Input from the request goes into the prompt. An attacker can write instructions that change what the model does, for example to leak the system prompt or call tools.

## Example

`openai.chat.completions.create({ messages: [{ role: 'user', content: req.body.q }] });`

```ts title="src/server.ts"
import express from "express";
import OpenAI from "openai";

const app = express();
const openai = new OpenAI();
app.use(express.json());

app.post("/support/ask", async (req, res) => {
  const answer = await openai.chat.completions.create({
    model: "gpt-4o-mini",
    messages: [{ role: "user", content: req.body.q }],
  });
  res.json(answer.choices[0].message);
});

app.listen(3000);
```
