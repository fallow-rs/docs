## What it reports

Runtime-reachable file has no test dependency path.

[Health](/analysis/health) explains how fallow finds it.

## Why it matters

No test imports the file, directly or through other modules. A change to the file can break production, and no test fails.

## Example

`src/routes/checkout.ts` imports `src/billing/invoice.ts`, but no test file imports either module, directly or through other modules.

```json title=".fallowrc.json"
{
  "rules": {
    "coverage-gaps": "warn"
  }
}
```

```ts title="src/billing/invoice.ts"
export const createInvoice = (orderId: string, total: number): string =>
  `Invoice for ${orderId}: ${total.toFixed(2)}`;
```

```ts title="src/routes/checkout.ts"
import { createInvoice } from "../billing/invoice";

console.log(createInvoice("order-1", 40));
```

```ts title="test/invoice.test.ts"
import { expect, it } from "vitest";
import { createInvoice } from "../src/billing/invoice";

it("formats the total", () => {
  expect(createInvoice("order-1", 40)).toBe("Invoice for order-1: 40.00");
});
```

## Fix

Add or wire a test that imports the runtime path, or update entry-point/test discovery if the existing test is invisible to fallow.
