## What it reports

Runtime-reachable file has no test dependency path.

[Health](/analysis/health) explains how fallow finds it.

## Why it matters

A file is reachable from runtime entry points but not from any discovered test entry point. This indicates production code that no test imports, directly or transitively, according to the static module graph.

## Example

Production-reachable code has no dependency path from discovered test entry points.

## Fix

Add or wire a test that imports the runtime path, or update entry-point/test discovery if the existing test is invisible to fallow.
