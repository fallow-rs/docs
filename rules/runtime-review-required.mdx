## What it reports

Statically used but never invoked in production.

[Runtime coverage](/analysis/runtime-coverage) explains how fallow finds it.

## Why it matters

The function is reachable in the module graph (or exercised by tests / untracked call sites) but was not invoked during the observed runtime coverage window. Needs a human look: may be seasonal, error-path only, or legitimately unused.

## Example

`src/reports/page.tsx` imports `exportCsv`, but the production capture shows no call to it.

## Fix

Ask the owner whether the path is seasonal, an error path or dead. Remove the call sites and the function when nobody needs them.

## When to keep the code

- The function runs only at some times of the year, or only on an error path. A capture window can miss it.
