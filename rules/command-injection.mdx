## What it reports

Catalogue security candidate for CWE-78.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

The shell parses the string, so an attacker who controls part of it can run other commands on the server. Check the trace before you fix.

## Example

`child_process.exec('convert ' + req.query.file + ' out.png');`

```ts title="src/server.ts"
import express from "express";
import child_process from "node:child_process";

const app = express();

app.get("/thumbnails", (req, res) => {
  child_process.exec("convert " + req.query.file + " out.png");
  res.sendStatus(202);
});

app.listen(3000);
```

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
