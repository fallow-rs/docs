## What it reports

"use client" file exports a server-only / route-config name.

[Architecture](/analysis/architecture) explains how fallow finds it.

## Why it matters

Next.js rejects the file when it compiles the route, so the page fails to build. The check reports the export before anyone opens the page or runs the build.

## Example

`app/page.tsx` starts with `"use client"` and exports `metadata`.

## Fix

Move the server-only export to a module without `"use client"`, such as a server component or `layout.tsx`. Or remove the directive when the module does not need to be a client boundary.
