## What it reports

Suppression comment or tag no longer matches any issue

[Suppress a finding](/guides/suppress) explains how fallow finds it.

## Why it matters

A fallow-ignore-next-line, fallow-ignore-file, or @expected-unused suppression that no longer matches any active issue. The underlying problem was fixed but the suppression was left behind. Remove it to keep the codebase clean.

## Example

// fallow-ignore-next-line unused-export remains above an export that is now used.

## Fix

Remove the suppression. If a different issue is still intentional, replace it with a current, specific suppression.
