## What it reports

Catalogue security candidate for CWE-327.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

The algorithm comes from a value at run time, or it is MD5, SHA-1, DES or RC4. With a weak algorithm, an attacker can forge hashes or decrypt the data.

## Example

`crypto.createHash(options.algorithm);`

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
