## What it reports

Catalogue security candidate for CWE-915.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

All properties of the request object go into the target. An attacker can set fields that the form never shows, such as a role or an owner ID. Check the trace before you fix.

## Example

`Object.assign(user, req.body);`

```ts title="src/server.ts"
import express from "express";

interface User {
  name: string;
  role: string;
}

const app = express();
const users = new Map<string, User>();
app.use(express.json());

app.patch("/users/:id", (req, res) => {
  const user = users.get(req.params.id) ?? { name: "", role: "customer" };
  Object.assign(user, req.body);
  users.set(req.params.id, user);
  res.json(user);
});

app.listen(3000);
```

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
