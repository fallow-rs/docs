## What it reports

Catalogue security candidate for CWE-1333.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

An attacker who controls the pattern can make the regular expression run for a long time and block the event loop. Check the trace before you fix.

## Example

`new RegExp(req.query.filter);`

```ts title="src/server.ts"
import express from "express";

const app = express();

app.get("/orders", (req, res) => {
  const pattern = new RegExp(req.query.filter as string);
  res.json({ matches: pattern.test("order-1001") });
});

app.listen(3000);
```

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
