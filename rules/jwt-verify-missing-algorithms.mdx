## What it reports

Catalogue security candidate for CWE-347.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

Without an `algorithms` allowlist, the token header chooses the algorithm. An attacker can then pick an algorithm that lets them forge a valid token.

## Example

`jwt.verify(token, publicKey, { audience: 'api' });`

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
