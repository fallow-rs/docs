## What it reports

Production dependency only used via type-only imports.

[Dependencies](/analysis/dependencies) explains how fallow finds it.

## Why it matters

Production dependencies that are only imported via `import type` statements. These can be moved to devDependencies since they generate no runtime code and are stripped during compilation.

## Example

zod is in dependencies but only appears in import type declarations.

```json title=".fallowrc.json"
{
  "production": true
}
```

```json title="package.json"
{
  "name": "shop",
  "private": true,
  "main": "src/index.ts",
  "dependencies": {
    "zod": "^3.23.0"
  }
}
```

```ts title="src/index.ts"
import type { ZodIssue } from "zod";

export const describeIssue = (issue: ZodIssue): string =>
  `${issue.path.join(".")}: ${issue.message}`;
```

## Fix

Move the package to devDependencies unless runtime code imports it as a value.
