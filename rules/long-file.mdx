## What it reports

File has more lines than the file-length threshold

[Health](/analysis/health) explains how fallow finds it.

## Why it matters

The file has more physical lines than `health.maxFileLines` (or `--max-file-lines`, or a `thresholdOverrides[].maxFileLines` entry for the file). Every line counts, also blank lines and comment lines; a final newline does not add a line. The threshold is off (`0`) by default. The finding is a complexity finding with `exceeded: "file_lines"`, the name `<file>`, the line count in `line_count`, and the ceiling in `max_file_lines`. The `complexity-file-lines` rule sets its gate severity. In `fallow audit`, a long file that did not grow by at least 5 lines stays inherited, and one that grew is worsened.

## Example

A module grew to 900 physical lines while `health.maxFileLines` is 500. Blank lines and comment lines count; a final newline does not add a line.

## Fix

Move cohesive groups of exports into their own modules, and remove unused code. In `fallow audit`, a long file that did not grow stays inherited, so you can enable the threshold on an existing project and stop further growth. To report these findings without a failed run, set the `complexity-file-lines` rule to `warn`. To raise the ceiling for generated files, use `thresholdOverrides[].maxFileLines`.
