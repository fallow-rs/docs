## What it reports

File has more lines than the file-length threshold.

[Health](/analysis/health) explains how fallow finds it.

## Why it matters

A long file is slow to review and to search. More changes touch the same file, so merge conflicts happen more often.

## Example

A module grew to 900 physical lines while `health.maxFileLines` is 500. Blank lines and comment lines count; a final newline does not add a line.

```json title=".fallowrc.json"
{
  "health": {
    "maxFileLines": 10
  }
}
```

```ts title="src/cart.ts"
export type Item = { sku: string; price: number; quantity: number };

export const subtotal = (items: Item[]): number =>
  items.reduce((sum, item) => sum + item.price * item.quantity, 0);

export const itemCount = (items: Item[]): number =>
  items.reduce((sum, item) => sum + item.quantity, 0);

export const isEmpty = (items: Item[]): boolean => items.length === 0;

export const findItem = (items: Item[], sku: string): Item | undefined =>
  items.find((item) => item.sku === sku);

export const removeItem = (items: Item[], sku: string): Item[] =>
  items.filter((item) => item.sku !== sku);
```

## Fix

Move cohesive groups of exports into their own modules, and remove unused code. In `fallow audit`, a long file that did not grow stays inherited, so you can enable the threshold on an existing project and stop further growth. To report these findings without a failed run, set the `complexity-file-lines` rule to `warn`.

To raise the ceiling for generated files, use `thresholdOverrides[].maxFileLines`.

## When to keep the code

- Generated files: set `maxFileLines` to `0` for them in a [`health.thresholdOverrides`](/reference/config-health#health-thresholdoverrides) entry with `files`.
- To hide one file, put `// fallow-ignore-file complexity` at the top. This comment also hides the function findings of the file.
