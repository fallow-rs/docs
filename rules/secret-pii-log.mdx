## What it reports

Catalogue security candidate for CWE-532.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

Logs go to more places and people than the data itself, and they stay for a long time. A secret or personal data in a log leaks to everyone who can read the logs.

## Example

`console.log('login', req.body.password);`

```ts title="src/server.ts"
import express from "express";

const app = express();
app.use(express.json());

app.post("/login", (req, res) => {
  console.log("login", req.body.email, req.body.password);
  res.sendStatus(204);
});

app.listen(3000);
```

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
