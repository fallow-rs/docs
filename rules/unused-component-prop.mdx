## What it reports

A Vue, Svelte, or React component prop is referenced nowhere in its own component.

[Dead code](/analysis/dead-code) explains how fallow finds it.

## Why it matters

Callers pass a value that the component ignores, so a caller can think that the prop changes the output. The prop also stays in the component type and in every call site.

## Example

Widget.vue declares defineProps\<\{ size: string \}>(), or a React Widget(\{ size \}) destructures `size`, but `size` is referenced nowhere in the component (Vue: its script or template; React: its function body or JSX).

```vue title="src/App.vue"
<script setup lang="ts">
import Widget from "./Widget.vue";
</script>

<template>
  <Widget title="Order total" size="large" />
</template>
```

```vue title="src/Widget.vue"
<script setup lang="ts">
defineProps<{ title: string; size: string }>();
</script>

<template>
  <section>
    <h2>{{ title }}</h2>
  </section>
</template>
```

## Fix

Remove the unused prop, or reference it in the component (Vue: the script / template; React: the function body or JSX). If the prop is part of a deliberately-stable public component API, suppress the line with // fallow-ignore-next-line unused-component-prop.
