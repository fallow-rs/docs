## What it reports

Catalogue security candidate for CWE-1333.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

The pattern can backtrack for a very long time on a crafted input string. An attacker can then block the event loop with one request.

## Example

`/^(a+)+$/.test(req.query.name);`

```ts title="src/server.ts"
import express from "express";

const app = express();

app.get("/users", (req, res) => {
  const valid = /^(a+)+$/.test(req.query.name as string);
  res.json({ valid });
});

app.listen(3000);
```

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
