## What it reports

Cold reachable uncovered code needs owner review.

[Runtime coverage](/analysis/runtime-coverage) explains how fallow finds it.

## Why it matters

Coverage intelligence found code that is statically reachable but cold in runtime evidence, uncovered by tests, and ownership-risky. Route it to an owner before changing or deleting it.

## Example

`syncLegacy` is reachable but never ran in production, no test covers it, and its file has no owner or an inactive owner.

## Fix

Give the code an owner, and let that owner decide whether to change or delete it.
