## What it reports

Catalogue security candidate for CWE-732.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

Mode `0o777` lets every user on the machine change the file. Another process can replace its content, for example a script that the application runs later.

## Example

`fs.chmodSync(scriptPath, 0o777);`
