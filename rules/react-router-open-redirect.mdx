## What it reports

Catalogue security candidate for CWE-601.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

The loader or action sends users to a URL that the input chooses. An attacker can use a trusted link of your domain to send users to a phishing page.

## Example

`return redirect(new URL(request.url).searchParams.get('next') ?? '/');`

```tsx title="app/routes/login.tsx"
import { redirect } from "react-router";

export const loader = ({ request }: { request: Request }): Response => {
  const next = new URL(request.url).searchParams.get("next") ?? "/";
  return redirect(next);
};
```

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
