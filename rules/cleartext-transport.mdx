## What it reports

Catalogue security candidate for CWE-319.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

The connection is not encrypted. Anyone on the network path can read and change the data that it carries.

## Example

`fetch('http://api.example.com/orders');`

```ts title="src/orders-client.ts"
export const fetchOrders = async () => {
  const response = await fetch("http://api.example.com/orders");
  return response.json();
};
```

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
