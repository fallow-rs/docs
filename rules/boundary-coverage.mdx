## What it reports

Source file matches no configured architecture boundary zone.

[Architecture](/analysis/architecture) explains how fallow finds it.

## Why it matters

A file outside every zone is outside every boundary rule, so it can import from any layer. New code in that file can break the architecture, and no check reports it.

## Example

src/generated/client.ts is reachable but does not match any boundaries.zones[].patterns entry.

## Fix

Add the file to the intended zone pattern, move it under a zoned directory, or add a generated-file glob to boundaries.coverage.allowUnmatched.
