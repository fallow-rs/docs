## What it reports

File is not reachable from any entry point

[Dead code](/analysis/dead-code) explains how fallow finds it.

## Why it matters

Source files that are not imported by any other module and are not entry points (scripts, tests, configs). These files can safely be deleted. Detection uses graph reachability from configured entry points.

## Example

src/old-widget.ts is not imported by any entry point, route, script, or config file.

## Fix

Delete the file if it is genuinely dead. If a framework loads it implicitly, add the right plugin/config pattern or mark it in alwaysUsed.
