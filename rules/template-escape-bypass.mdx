## What it reports

Catalogue security candidate for CWE-79.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

The template engine skips HTML escaping for the wrapped value. If an attacker controls it, their markup and script reach the page. Check the trace before you fix.

## Example

`return new Handlebars.SafeString(user.bio);`

```ts title="src/profile.ts"
import Handlebars from "handlebars";

interface Profile {
  bio: string;
}

export const profileBio = (profile: Profile): Handlebars.SafeString =>
  new Handlebars.SafeString(profile.bio);
```

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
