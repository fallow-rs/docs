## What it reports

Catalogue security candidate for CWE-347.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

A token signed with `none` has no signature. Anyone can change its claims, and a verifier that accepts `none` treats the token as valid.

## Example

`jwt.sign(payload, '', { algorithm: 'none' });`

```ts title="src/token.ts"
import jwt from "jsonwebtoken";

export const issueCartToken = (cartId: string): string => {
  const payload = { cartId };
  return jwt.sign(payload, "", { algorithm: "none" });
};
```
