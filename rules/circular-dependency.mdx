## What it reports

Circular dependency chain detected.

[Architecture](/analysis/architecture) explains how fallow finds it.

## Why it matters

A cycle in the module import graph. Circular dependencies cause undefined behavior with CommonJS (partial modules) and initialization ordering issues with ESM. Break cycles by extracting shared code.

## Example

`src/cart.ts` imports `src/order.ts`, and `src/order.ts` imports `src/cart.ts`.

```ts title="src/cart.ts"
import { orderTotal } from "./order";

export const cartItems: number[] = [];

export const cartTotal = (): number => orderTotal();
```

```ts title="src/order.ts"
import { cartItems } from "./cart";

export const orderTotal = (): number =>
  cartItems.reduce((sum, price) => sum + price, 0);
```

## Fix

Extract shared code to a third module, invert the dependency, or split initialization-time side effects from type-only contracts.

## When to keep the code

- An import that loads no code is not a risk at run time. TypeScript removes a plain import when the file never reads the imported names as values. Fallow does not count such an import in a loop:
  - an `import type`;
  - a plain import whose names are all interfaces or type aliases in the other file;
  - a plain import that a `.ts`, `.mts` or `.cts` file uses only in type positions or not at all, also of a class.
- Fallow still counts a plain import when TypeScript keeps it:
  - the tsconfig of the importing file sets `verbatimModuleSyntax` or `preserveValueImports`, or its `extends` chain does not resolve;
  - the importing file is a `.tsx` file, because the import can be the JSX factory;
  - the file has a decorator and the tsconfig sets `emitDecoratorMetadata`.
- To accept one loop on purpose, list its files in [`circularDependencies.allow`](/reference/config-architecture#circulardependencies-allow). Fallow still reports a new loop that goes through some of these files and another file.
- A dynamic `import()` is part of a loop by default. To leave out the imports that load later, set [`circularDependencies.ignoreLazyImports`](/reference/config-architecture#circulardependencies-ignorelazyimports).
