## What it reports

CSS or CSS-in-JS reference resolves to no stylesheet definition.

[Styling](/analysis/styling) explains how fallow finds it.

## Why it matters

The class or animation name has no definition, so the element gets no style or no animation. The browser reports no error, so the defect shows only on screen.

## Example

src/app.css sets `animation: fade-in 1s`, but no stylesheet defines `@keyframes fade-in`. Or markup uses `class="nav-item"` where only `.nav-items` exists.

## Fix

Correct the name or add the missing definition. Keep the reference when a CSS-in-JS library or an external stylesheet defines the name.
