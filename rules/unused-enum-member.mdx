## What it reports

Enum member is never referenced.

[Dead code](/analysis/dead-code) explains how fallow finds it.

## Why it matters

Readers treat each enum member as a state that can occur, so switch statements, mappings and tests keep a branch for a value that no code uses.

## Example

Status.Legacy remains in an exported enum, but no code reads that member.

```ts title="src/index.ts"
import { Status } from "./status";

const order = { status: Status.Paid };
console.log(order.status === Status.Shipped ? "on its way" : "waiting");
```

```ts title="src/status.ts"
export enum Status {
  Paid = "paid",
  Shipped = "shipped",
  Legacy = "legacy",
}
```

## Fix

Remove the member after checking serialized/API compatibility, or suppress it with a reason when external data still uses it.
