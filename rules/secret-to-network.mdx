## What it reports

Catalogue security candidate for CWE-201.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

A secret from the environment leaves the process in a network request. If the destination or the payload is not the intended one, the secret leaks.

## Example

`fetch(endpoint, { body: process.env.API_KEY });`

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
