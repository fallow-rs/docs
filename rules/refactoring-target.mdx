## What it reports

File identified as a high-priority refactoring candidate.

[Health](/analysis/health) explains how fallow finds it.

## Why it matters

File identified as a refactoring candidate based on a weighted combination of complexity density, churn velocity, dead code ratio, fan-in (blast radius), and fan-out (coupling). Categories: urgent churn+complexity, break circular dependency, split high-impact file, remove dead code, extract complex functions, reduce coupling.

## Example

A file combines high complexity density, churn, fan-in, and dead-code signals.

```ts title="src/cart.ts"
type Item = { price: number; quantity: number };

export const subtotal = (items: Item[]): number =>
  items.reduce((sum, item) => sum + item.price * item.quantity, 0);

export const itemCount = (items: Item[]): number =>
  items.reduce((sum, item) => sum + item.quantity, 0);

export const isEmpty = (items: Item[]): boolean => items.length === 0;
```

```ts title="src/index.ts"
import { subtotal } from "./cart";

console.log(subtotal([{ price: 10, quantity: 2 }]));
```

## Fix

Start with the listed evidence: remove dead exports, extract complex functions, then reduce fan-out or cycles in small steps.
