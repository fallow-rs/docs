## What it reports

Catalogue security candidate for CWE-611.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

An XML parser that resolves external entities can read local files or send requests for the attacker. A crafted XML document is enough.

## Example

`libxmljs.parseXml(req.body, { noent: true });`

```ts title="src/server.ts"
import express from "express";
import libxmljs from "libxmljs";

const app = express();
app.use(express.text({ type: "application/xml" }));

app.post("/orders/import", (req, res) => {
  const doc = libxmljs.parseXml(req.body, { noent: true });
  res.json({ orders: doc.find("//order").length });
});

app.listen(3000);
```

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
