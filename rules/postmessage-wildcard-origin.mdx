## What it reports

Catalogue security candidate for CWE-346.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

With `*` as the target origin, any page that holds the window reference receives the message, including a page of an attacker.

## Example

`window.parent.postMessage({ token }, '*');`

```ts title="src/checkout-frame.ts"
export const sendCheckoutToken = (token: string) => {
  window.parent.postMessage({ token }, "*");
};
```

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
