## What it reports

Catalogue security candidate for CWE-1188.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

The buffer holds old memory of the process until the code overwrites it. If the code sends the buffer before it fills it, earlier data such as secrets can leak.

## Example

`const buffer = Buffer.allocUnsafe(size);`

```ts title="src/receipt.ts"
export const encodeReceipt = (lines: string[], size: number): Buffer => {
  const buffer = Buffer.allocUnsafe(size);
  let offset = 0;
  for (const line of lines) {
    offset += buffer.write(`${line}\n`, offset);
  }
  return buffer;
};
```

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
