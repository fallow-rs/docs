## What it reports

Catalogue security candidate for CWE-89.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

The connection runs more than one statement per query. A small SQL injection anywhere in the application can then append statements that drop or change tables.

## Example

`mysql.createConnection({ host, user, multipleStatements: true });`

```ts title="src/db.ts"
import mysql from "mysql";

export const connection = mysql.createConnection({
  host: "localhost",
  user: "shop",
  multipleStatements: true,
});
```

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
