## What it reports

CSS or CSS-in-JS surface appears unused.

[Styling](/analysis/styling) explains how fallow finds it.

## Why it matters

The unused style still ships to users and still gets updated in redesigns. A dead scoped class often means that the markup changed and the style stayed behind.

## Example

Card.vue defines `.card__badge` in `<style scoped>`, but no part of the component uses that class.

## Fix

Delete the unused class after you check that no code adds it at runtime, for example through a class name built from a variable.

## When to keep the code

- Code builds the class name at run time, or code outside the project uses the styling. Fallow cannot see these uses.
