## What it reports

Static and runtime evidence indicate code can be deleted.

[Runtime coverage](/analysis/runtime-coverage) explains how fallow finds it.

## Why it matters

No code imports the code, production does not run it and no test reaches it. It costs reading and upkeep in each refactor, and nothing depends on it.

## Example

No module references `oldExport`, the production capture shows no call to it, and no test reaches it.

## Fix

Confirm with the owner of the file, then delete the code.
