## What it reports

Catalogue security candidate for CWE-918.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

The server sends a request to a URL that the input chooses. An attacker can reach internal services or cloud metadata endpoints through it. Check the trace before you fix.

## Example

`fetch(req.query.url);`

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
