## What it reports

Production dependency only imported by test files.

[Dependencies](/analysis/dependencies) explains how fallow finds it.

## Why it matters

Production dependencies that are only imported from test files. These can usually move to devDependencies because production entry points do not require them at runtime.

## Example

vitest is listed in dependencies, but only test files import it.

```json title="package.json"
{
  "name": "shop",
  "private": true,
  "main": "src/cart.ts",
  "dependencies": {
    "vitest": "^5.1.1"
  }
}
```

```ts title="src/cart.test.ts"
import { expect, it } from "vitest";
import { cartTotal } from "./cart";

it("adds the prices", () => {
  expect(cartTotal([2, 3])).toBe(5);
});
```

## Fix

Move the package to devDependencies unless production code imports it at runtime.
