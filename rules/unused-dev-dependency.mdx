## What it reports

Dev dependency listed but never imported.

[Dependencies](/analysis/dependencies) explains how fallow finds it.

## Why it matters

Packages listed in devDependencies that are never imported by test files, config files, or scripts. Build tools and jest presets that are referenced only in config may appear as false positives.

## Example

package.json lists left-pad, but no source, script, config, or plugin-recognized file imports it.

## Fix

Remove the dependency after checking runtime/plugin usage. If another workspace uses it, move the dependency to that workspace.
