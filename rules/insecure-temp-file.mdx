## What it reports

Catalogue security candidate for CWE-377.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

Other users can predict a fixed path in a shared temporary folder. They can create the file first or link it to another file, so the application reads or overwrites the wrong data.

## Example

`fs.writeFileSync('/tmp/report.json', data);`

```ts title="src/report.ts"
import fs from "node:fs";

export const saveOrderReport = (data: string) => {
  fs.writeFileSync("/tmp/report.json", data);
};
```

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
