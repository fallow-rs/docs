## What it reports

Runtime coverage could not be resolved for this function

[Runtime coverage](/analysis/runtime-coverage) explains how fallow finds it.

## Why it matters

The function could not be matched to a V8-tracked coverage entry. Common causes: the function lives in a worker thread (separate V8 isolate), it is lazy-parsed and never reached the JIT tier, or its source map did not resolve to the expected source path. This is advisory, not a dead-code signal.

## Example

Runtime coverage shows a function was never called, barely called, or could not be matched during the capture window.

## Fix

Treat high-confidence cold static-dead code as delete candidates. For advisory or unavailable coverage, inspect seasonality, workers, source maps, and capture quality first.
