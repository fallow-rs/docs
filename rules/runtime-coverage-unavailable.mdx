## What it reports

Runtime coverage could not be resolved for this function.

[Runtime coverage](/analysis/runtime-coverage) explains how fallow finds it.

## Why it matters

fallow has no runtime data for the function, so it cannot tell if production runs it. A decision to delete or keep the function has no runtime evidence.

## Example

`renderChart` runs in a worker thread, so the capture of the main process has no coverage entry for it.

## Fix

Capture coverage in the worker too, or check that the source maps map the bundle to the source file. Do not delete code because of this finding.
