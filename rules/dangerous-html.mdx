Dangerous HTML sink is a data-driven `fallow security` tainted-sink catalogue category with CWE-79 metadata. fallow reports it as an unverified candidate when a captured sink shape matches this category. Use it to understand or filter `security/dangerous-html` findings, then inspect the trace, source, sink, sanitization, and application context before treating it as exploitable.
