## What it reports

Detected feature flag pattern.

[Feature flags](/analysis/feature-flags) explains how fallow finds it.

## Why it matters

A feature flag pattern detected by `fallow flags`: environment-variable checks, flag SDK calls (LaunchDarkly, Unleash, and similar), or config-object lookups. Long-lived flags accumulate dead branches; review old flags for retirement and pair with dead-code analysis to find branches that can no longer execute.

## Example

`src/checkout.ts` checks `process.env.FEATURE_NEW_CHECKOUT === 'true'`, or calls `client.variation('new-checkout', user, false)` of a flag SDK.

```ts title="src/checkout.ts"
const newCheckout = (): string => "new checkout";
const oldCheckout = (): string => "old checkout";

export const checkout = (): string =>
  process.env.FEATURE_NEW_CHECKOUT === "true" ? newCheckout() : oldCheckout();
```

## Fix

Check if the flag still switches behavior. Run `fallow flags --retirement` to list the flags that are ready to go, then remove the flag check and the branch that production no longer runs.
