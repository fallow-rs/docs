## What it reports

Catalogue security candidate for CWE-94.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

The runtime executes the string as code. If an attacker controls it, they run code with the rights of the process. Check the trace before you fix.

## Example

`eval(req.body.expression);`

```ts title="src/server.ts"
import express from "express";

const app = express();

app.use(express.json());

app.post("/cart/discount", (req, res) => {
  const discount = eval(req.body.expression);
  res.json({ discount });
});

app.listen(3000);
```

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
