## What it reports

Import could not be resolved.

[Dead code](/analysis/dead-code) explains how fallow finds it.

## Why it matters

When the runtime or the bundler cannot resolve the path either, the build fails or the module throws when it loads. fallow also loses the edge, so the files behind it can show up as unused.

## Example

`src/app.ts` imports ./routes/admin, but no matching file exists after extension and index resolution.

```ts title="src/app.ts"
import { adminRoutes } from "./routes/admin";
import { shopRoutes } from "./routes/shop";

console.log([...shopRoutes, ...adminRoutes]);
```

```ts title="src/routes/shop.ts"
export const shopRoutes = ["/cart", "/checkout"];
```

## Fix

Fix the specifier, restore the missing file, install the package, or align tsconfig path aliases with the runtime resolver.
