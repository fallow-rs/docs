## What it reports

Catalogue security candidate for CWE-400.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

A size that comes from the request controls how much memory the code allocates. One request with a large value can exhaust the memory of the process.

## Example

`new Array(Number(req.query.count));`

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
