## What it reports

CSS or CSS-in-JS declaration block is duplicated across rules.

[Styling](/analysis/styling) explains how fallow finds it.

## Why it matters

A style rule declaration block is repeated across selectors, suggesting copy-pasted styling that can often be consolidated. The finding is advisory by default and does not affect the audit verdict unless rules.css-duplicate-block is set to error.

## Example

`.card` in `src/card.css` and `.panel` in `src/panel.css` declare the same four or more declarations.

```css title="src/card.css"
.card {
  padding: 16px;
  border: 1px solid #ddd;
  border-radius: 8px;
  background: white;
}
```

```css title="src/panel.css"
.panel {
  padding: 16px;
  border: 1px solid #ddd;
  border-radius: 8px;
  background: white;
}
```

## Fix

Move the shared declarations to one class or a shared mixin, and use it from both places.
