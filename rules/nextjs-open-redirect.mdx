## What it reports

Catalogue security candidate for CWE-601.

[Security](/analysis/security) explains how fallow finds it.

## Why it matters

The route sends users to a URL that the input chooses. An attacker can use a trusted link of your domain to send users to a phishing page.

## Example

`redirect(request.nextUrl.searchParams.get('next'));`

```ts title="app/login/route.ts"
import { redirect } from "next/navigation";
import type { NextRequest } from "next/server";

export const GET = (request: NextRequest): never => {
  redirect(request.nextUrl.searchParams.get("next") ?? "/");
};
```

## Fix

Review the candidate trace before acting. Confirm attacker control, missing sanitization, and reachable runtime context, then fix with the category-appropriate safer API or add a reviewed suppression.
