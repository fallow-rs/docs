## What it reports

Export name appears in multiple modules.

[Dead code](/analysis/dead-code) explains how fallow finds it.

## Why it matters

The same export name is defined in multiple modules. Consumers may import from the wrong module, leading to subtle bugs. Consider renaming or consolidating.

## Example

Button is exported from both src/ui/button.ts and src/components/button.ts.

## Fix

Rename or consolidate the exports so consumers have one intentional import target.

## When to keep the code

- A wrapper exports its own version of a name that it imports from another file. Fallow reports this pair, because importers see two exports with different behavior. To keep the wrapper, add `// fallow-ignore-next-line duplicate-export` above its export, or add the name to [`ignoreExports`](/reference/config-dead-code#ignoreexports).

## Notes

Fallow does not report an overlay: a file that has `export * from` a module and also replaces one of its names.
